# Third-party components

TapeBloom's original source is MIT licensed. JUCE is downloaded by CMake and
is not included in this source archive. The pinned release is JUCE 8.0.6,
commit 51a8a6d7aeae7326956d747737ccf1575e61e209.

JUCE's own LICENSE.md specifies AGPLv3 or a commercial JUCE licence. The
original-source MIT licence does not replace JUCE's terms for the combined
application. Keep JUCE and its dependency licence notices with distributed
builds and provide the corresponding source if using the AGPL route.

See the dependency's exact licence:
https://github.com/juce-framework/JUCE/blob/8.0.6/LICENSE.md

No factory tapes, Mellotron recordings, or third-party instrument samples are
included. Mellotron is used only to describe the inspiration, not as the
application's name or logo. Users record/import their own audio.
